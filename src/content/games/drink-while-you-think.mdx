-   A drink each

<GameSection title="Setup" icon="/images/settings.webp">
No setup needed, get everyone within shouting distance with a drink in their hand.

</GameSection>

<GameSection title="Aim of the Game" icon="/images/target.webp">
<p>Come up with quick answers to limit the time you're drinking.</p>
</GameSection>

<GameSection title="How to Play" icon="/images/question.webp">
The game starts with the first person in the circle saying for example the name of a celebrity or someone famous out loud to the group (e.g. Bruce Willis).

The next person in the circle would then say the name of another celebrity, first name starting with the same letter as the previous last name (e.g. Wayne Rooney).

The game continues until somebody chokes, passes or gives up.

The player who gives up first must take a shot.
</GameSection>

<GameSection title="Rules" icon="/images/rules.webp">
-   If a player does not drink whilst they think, an appeal can be made by other players as to how many seconds of drinking they should do as punishment.
-   If a person gives an incorrect answer or a repeat answer, they must continue to think and drink until a successful answer is given. After this they must pay a drink debt of 3 seconds.
-   If a person cannot think of an answer, they get 1 pass per game which costs a drink debt of 5 seconds.
</GameSection>

<GameSection title="Special Edition" icon="/images/special.webp">

<h4>Reverse move</h4>

-   If the first and last names start with the same letter, the order of play is reversed.
</GameSection>
